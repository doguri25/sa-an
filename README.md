# 사안 접수 (sa-an)

초등학교 **학교폭력 담당교사 시뮬레이션**. 신고가 들어온 순간부터 48시간 보고, 보호자 통보, 분리, 조사와 면담, 전담기구, 심의위원회, 생활기록부 기재와 종결 후 추적까지 — 담당교사가 실제로 겪는 절차를 하루 단위로 굴리는 게임입니다. 서버 없이 브라우저 한 파일로 돌아가며, PWA로 홈 화면에 추가하면 오프라인에서도 실행됩니다.

- 만든이: 도구리 (홍북초등학교) · raccoon@ai.cne.go.kr
- 참고: 교육부 학교폭력 사안처리 가이드북(공공누리)
- 현재 버전: **v3.1.0** (버전 기록은 앱의 더보기 → 「만든이」)

## 무엇을 하는 게임인가

- **사안 원형 17종**: 복도 밀침, 단톡방 저격, 편의점 심부름(금품), 술래잡기 충돌(학폭 아님), 급식 따돌림, 축구 골대 다툼(쌍방·2주), SNS 합성 사진, 게임 아이템 강요, 별명 놀림, 등하굣길 위협, 허위 신고 의심, 화장실 촬영, 안경 파손, 전학생 배제, 익명 협박 쪽지, 방과후 교실 형제 사안, 교사 개입 사안(교권침해 병행). 거짓말 슬롯·증거 슬롯·극단 이벤트·보호자 성향·가정 배경·학생 특성·신고 경로가 회차마다 바뀝니다.
- **하루의 리듬**: 평일 슬롯(난이도별 8~4, 수업 시수만큼 차감)로 행동을 고르고 「계속」으로 하루를 넘깁니다. 이틀 연속 다 쓰면 소진이 오르고 소진 5면 병가.
- **절차가 곧 규칙**: 48시간 보고(교감 결재), 통보 기록, 즉시 분리, 개별 확인서, 면담(보호자 동석·상담교사 배석·학생만), 증거, 조사 보고서(결재), 전담기구 소집·보호조치·자체해결/심의위, 심의위 출석 답변, 결과와 「진실대로였다면」, 불복·기재·이행 확인·재발 점검.
- **사람들**: 성향이 있는 교감·교장, 담임의 입장, 보호자 성향과 가정 배경, 상담교사·보건교사, 외부 목격자. 대화는 상대의 답에 이어지는 후속 질문으로 흐릅니다.
- **압박**: 동시 진행 사안, 보호자 요구 덱(연락처·만남 주선·학급 교체·담임 교체·전학·공개 사과), 극단 이벤트(교감 압박·민원·폭언·변호사·경찰·언론 보도·감사), 관리자의 잘못된 지시, 공문 회신 기한, 장학사 지도점검, 실태조사 시즌, 학기 달력.
- **연수용**: 강사 코드(QR)로 같은 사안을 여러 사람이 풀고 결과 코드(QR)로 점수표를 만들고, 결과 화면의 토론 카드로 이야기합니다. 진술 모순 힌트, 난이도 5단계, 약점 리포트, 통계 대시보드.

## 실행

- 그냥 열기: `index.html`을 브라우저에서 열면 됩니다(파일로 열 때는 PWA·외부 글꼴 없이 동작).
- 배포: 이 저장소를 Vercel(또는 GitHub Pages 등 정적 호스팅)에 연결하면 끝입니다. 5개 파일이 같은 폴더에 있어야 PWA가 동작합니다.

```
index.html            앱 전체(단일 파일)
sw.js                 서비스 워커(오프라인 캐시)
manifest.webmanifest  PWA 매니페스트
icon-192.png / icon-512.png
vercel.json           캐시·헤더 설정
```

- AI 자유 질문(선택): 설정에 클로드·챗GPT·제미나이 API 키를 넣으면 면담에서 자유 질문이 열립니다. 키는 브라우저에만 저장되고 저장 코드에도 포함되지 않습니다.

## 저장과 이동

진행은 브라우저(localStorage)에 자동 저장됩니다. 설정 → 「저장 코드 내보내기/불러오기」로 다른 기기에 옮길 수 있습니다.
